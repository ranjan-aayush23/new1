# Medicine Veda - Health & Wellness Website

A visually stunning, responsive website for the Medicine Veda YouTube health and wellness channel. The website features a soothing, professional, and clean design with a color palette of soft greens, white, and light blue, representing health and calmness.

## Features

- **Fully Responsive Design**: Looks great on all devices from mobile phones to large desktop monitors
- **Modern UI/UX**: Clean design with smooth animations and transitions
- **Dark/Light Mode Toggle**: User preference saved in local storage
- **Smooth Scroll Behavior**: Enhanced navigation experience
- **Subscription Popup**: Appears after 10 seconds to encourage visitors to subscribe
- **Animated Elements**: Using AOS (Animate on Scroll) library for elegant scroll animations
- **Contact Form**: Includes form validation (frontend only)
- **Embedded YouTube Videos**: Showcases featured content from the channel
- **Mobile-Friendly Navigation**: Hamburger menu for smaller screens

## Technologies Used

- **HTML5**: For structure and content
- **CSS3**: For styling, animations, and responsive design
- **JavaScript**: For interactivity and dynamic content
- **Google Fonts**: Montserrat and Poppins for modern typography
- **Font Awesome**: For icons throughout the site
- **AOS Library**: For scroll-triggered animations

## Pages & Sections

1. **Header/Navigation**: Sticky navbar with logo and menu links
2. **Hero Section**: Eye-catching introduction with call-to-action
3. **About Section**: Information about Medicine Veda and its services
4. **Featured Videos**: Embedded YouTube videos with descriptions
5. **Wellness Blog**: Preview cards for blog content
6. **Contact Section**: Contact form and social media links
7. **Footer**: Additional navigation, social links, and subscription form

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser to view the website
3. Modify content in HTML files as needed
4. Customize styles in the CSS files
5. Extend functionality with JavaScript as required

## Customization

- **Colors**: Edit the root variables in `css/styles.css`
- **Content**: Update text and images in `index.html`
- **Videos**: Replace YouTube embed links with actual Medicine Veda videos
- **Contact**: Update the email and social media links
